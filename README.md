
# 🛒 BazarDor — বাজার দর

### Your Everyday Market Price Guide

Explore essential grocery and food prices in one place, including rice, lentils, vegetables, fish, and meat.

BazarDor is a web application designed to make everyday market price information easier to explore through a clean, responsive interface.

**🌐 Live Demo:** https://as-7-bazardor.vercel.app

**💻 Repository:** https://github.com/fahmidulparvezt-pixel/As-7-Bazardor

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Frontend Library:** React
- **Language:** JavaScript / TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** DaisyUI
- **Data Fetching:** Fetch API
- **Notifications:** React Hot Toast
- **Deployment:** Vercel

## ✨ Key Features

- **Product Price Listings:** Browse prices of essential everyday products.
- **Category-Based Filtering:** Filter products by categories such as rice, lentils, vegetables, fish, and meat.
- **Product Details:** View detailed information about individual products.
- **Category Navigation:** Explore available product categories easily.
- **Responsive Design:** Enjoy a user-friendly experience on mobile, tablet, and desktop devices.
- **Dynamic Data Fetching:** Retrieve product and category data from the API.
- **Clean User Interface:** Navigate the application through a simple and intuitive layout.


## 🚀 Run Locally

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/fahmidulparvezt-pixel/As-7-Bazardor.git
   ```

2. Navigate to the project directory:

   ```bash
   cd As-7-Bazardor
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure environment variables if required by the project:

   ```bash
   cp .env.example .env.local
   ```

   Fill in the required values in `.env.local`.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.
